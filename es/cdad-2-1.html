CDAD 2.1

Implementación de Referencia Actual

CDAD 2.1 es la implementación de referencia actual que proporciona un workspace de proyecto gobernado con contexto explícito, decisiones arquitectónicas e integración de agentes.

¿Qué es CDAD 2.1?

CDAD 2.1 es una implementación concreta de la metodología CDAD que proporciona estructura de gobernanza e integración con agentes de IA de codificación.

El bootstrap introduce un workspace gobernado que contiene artefactos de gobernanza y contexto como:

  • AGENTS.md — Instrucciones de agentes y gobernanza
  • CHANGE-REQUEST.md — Plantilla para cambios propuestos
  • cdad/context/ — Contexto de proyecto gobernado (L0)
  • cdad/adr/ — Registros de Decisiones Arquitectónicas (L1)
  • cdad/proposals/ — Propuestas pendientes de revisión
  • cdad/scripts/ — Scripts de validación y gobernanza
  • .claude/, .kiro/ — Configuración específica del agente

Estructura del Workspace

El workspace CDAD organiza artefactos de gobernanza e implementación.

/
├── INDEX.md
├── AGENTS.md
├── CHANGE-REQUEST.md
│
├── cdad/
│ ├── README.md
│ ├── context/ (L0: Gobernado)
│ │ ├── stack.md
│ │ ├── principles.md
│ │ └── constraints.md
│ ├── adr/ (L1: Decisiones)
│ ├── proposals/ (Bajo revisión)
│ └── scripts/ (Gobernanza)
│
├── .claude/ (Configuración de Claude Code)
└── .kiro/ (Configuración de Kiro)

Agentes Soportados

CDAD 2.1 proporciona integraciones para múltiples agentes de IA de codificación.

Claude Code

Configuración a través del directorio `.claude/` con reglas CLAUDE.md y gobernanza en settings.json.

Kiro

Configuración a través del directorio `.kiro/` con manifiestos de dirección y directivas de gobernanza.

Cursor & Otros

El enfoque portable de gobernanza funciona con otros agentes de IA de codificación y entornos de desarrollo.

Metodología Primero

CDAD no está vinculado a ningún agente específico. La metodología es portable entre herramientas.

Comenzando

Cómo usar CDAD 2.1 en tu proyecto.

Repositorio Oficial de Bootstrap

https://github.com/CDAD-Community/cdad-bootstrap

El proyecto bootstrap es la implementación de referencia autoritativa. Clónalo, adáptalo a tu proyecto y sigue el proceso de configuración documentado.

1. Inicializar

Clona bootstrap y adapta la estructura del workspace a tu proyecto.

2. Establecer Contexto

Define arquitectura, principios y restricciones explícitamente en cdad/context/.

3. Integración de Agentes

Configura .claude/ o .kiro/ con reglas de gobernanza específicas para tus agentes.

4. Freeze

Revisa y ratifica tu contexto gobernado a través del proceso de freeze.

5. Trabajo

Comienza desarrollo con agentes trabajando dentro de los límites gobernados.
