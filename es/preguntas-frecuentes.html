CDAD Respondido

Preguntas comunes sobre CDAD, sus conceptos y cómo empezar.

¿Qué es CDAD?

CDAD (Context-Driven AI Development) es una metodología de código abierto para desarrollo de software asistido por IA gobernado. Proporciona una capa de gobernanza alrededor de agentes de IA de codificación para preservar la intención arquitectónica y reducir la desviación mientras el agente construye software.

¿Qué problema resuelve CDAD?

CDAD aborda la desviación arquitectónica: cuando un agente de IA hace cambios individualmente razonables que colectivamente alejan un sistema de su diseño previsto. También resuelve pérdida de contexto, cambios incontrolados y decisiones inconsistentes entre sesiones de desarrollo de IA.

¿Es CDAD un reemplazo para SDD?

No. CDAD complementa SDD (Spec-Driven Development). SDD define QUÉ construir; CDAD gobierna CÓMO un agente de IA debe operar mientras lo construye. Funcionan juntos efectivamente en el mismo proyecto.

¿Es CDAD un agente de IA de codificación?

No. CDAD es una metodología y un enfoque de gobernanza. No es un sistema de IA en sí. CDAD está diseñado para funcionar CON diferentes agentes de IA de codificación (Claude Code, Kiro, Cursor, etc.).

¿Qué es el Context Protection Pattern (CPP)?

CPP es un patrón central de CDAD que protege el contexto crítico del proyecto de ser libremente modificado por un agente de IA. En lugar de modificación libre, el agente debe proponer cambios a través de un flujo de trabajo controlado con revisión humana.

¿Depende CDAD de un proveedor específico de IA?

No. CDAD es independiente de proveedores y está diseñado para ser portable entre diferentes agentes de IA de codificación y entornos de desarrollo. La metodología en sí no está vinculada a ningún agente específico.

¿Puede CDAD funcionar con diferentes agentes de IA de codificación?

Sí. La implementación de referencia actual documenta integraciones con Claude Code, Kiro y Cursor. CDAD puede adaptarse para funcionar con otros agentes de IA de codificación y herramientas de desarrollo.

¿Por dónde comienzo con CDAD?

Comienza con el proyecto oficial CDAD Bootstrap en https://github.com/CDAD-Community/cdad-bootstrap. Clónalo, comprende la estructura de contexto gobernado, luego adapta el framework y reglas de gobernanza a tu proyecto y necesidades específicas.

¿Es CDAD código abierto?

Sí. CDAD es una metodología de código abierto. La implementación de referencia bootstrap está disponible en GitHub bajo una licencia Creative Commons Attribution 4.0.

¿Quién creó CDAD?

CDAD fue creado por Moisés Griott y ahora es mantenido por CDAD Community como un proyecto de código abierto.
