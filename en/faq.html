FAQ

Frequently Asked Questions

Common questions about CDAD.

What is CDAD?

CDAD is an open-source methodology for governed AI-assisted software development that combines specifications, context governance, and protection patterns.

What problem does CDAD solve?

Architectural drift — when AI-generated changes gradually move a system away from its intended design. CDAD provides mechanisms to make context explicit, governed and protected.

Is CDAD a replacement for SDD?

No. CDAD complements SDD. SDD defines what to build; CDAD governs the context and boundaries that guide an AI agent while building it.

Is CDAD an AI coding agent?

No. CDAD is a methodology and governance approach, not an AI agent itself, but a framework for governing how AI agents behave.

What is CPP (Context Protection Pattern)?

CPP is a CDAD pattern for protecting governed context. Instead of free modification, agents propose changes through a controlled workflow for human review.

Does CDAD depend on one vendor?

No. CDAD is vendor-independent and works with Claude Code, Kiro, Cursor, Copilot and other AI coding agents.
